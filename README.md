# 毛豆·昼夜交替 Maodou Shift

A single-file HTML5 pixel platformer for **GitHub Game Off 2026** (theme: **SHIFT**).

Press **Shift** and the world flips: day becomes night, night becomes day.
Platforms, spikes and shards only exist in one world. Collect every sun
and moon shard, then reach the door.

按 **Shift** 键，白天与黑夜瞬间对调——只在对应世界里存在的平台、
尖刺和收集物随之切换。小豆苗毛豆要在两个世界里穿梭，集齐碎片、走到门口过关。

## Play

Open `index.html` in any modern browser (or serve the folder with any
static server). No build step, no dependencies, no server needed.

- **Move**: WASD / Arrow keys · 移动：WASD / 方向键
- **Jump**: Space · 跳跃：空格（按住跳得更高）
- **Shift world**: Shift key · 切换世界：Shift 键
- **Restart level**: R · 重开本关：R
- Touch buttons appear on mobile.

3 levels, about 10 minutes to finish. Web Audio sound effects
(jump / shift / collect / win) — no audio files needed.
